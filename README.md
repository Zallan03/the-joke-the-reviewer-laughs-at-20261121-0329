## What it does

`main.py` (Python stdlib only, no network, no randomness) writes a single
one-line joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to
`/output/entry.txt` when the variable is unset). The joke is a constant
string in the program, so every run produces byte-identical output.
